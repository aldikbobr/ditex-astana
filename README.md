# Di-Tex — концепт сайта

Концепт-сайт салона штор **Di-Tex** (Астана, проспект Аль-Фараби, 44/1).

- Сайт: https://ditex-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.
- Зачем: домен ditex.kz из карточки 2ГИС сейчас перенаправляет на чужой сайт (teachers.kz), а в Google Картах салона не нашлось.

## Что внутри
- Прелоадер «раздвигающиеся шторы», плавный скролл (Lenis), сцены GSAP ScrollTrigger.
- Первый экран: окно-арка с тюлем, который колышется и тянется за курсором; «живая» волна ткани.
- Примерочная: комната, тип (шторы + тюль, плотные, тюль, римская) и 6 цветов — шторы на нарисованном окне меняются вживую; вариант уходит в WhatsApp.
- Услуги с «зубчатым» краем как у образцов ткани, таймлайн с рисующейся линией, галерея, карусель отзывов, заявка на выезд дизайнера → WhatsApp.

## Источники данных (проверено 08.10.2026)
- 2ГИС: рейтинг 4,8 / 763 отзыва, адрес, телефоны, WhatsApp, Telegram, часы (пн, чт–вс 10:00–19:00; вт–ср выходной — проверить у салона), услуга «Выезд дизайнера с образцами тканей», доставка, способы оплаты, отзывы.
